The official Paddle-Lite-Demo CPU archive supplies the ARM64 runtime.
FPInk modifies the runtime's non-loaded .dynsym section-header sh_info field
from 3 to 10, correcting an upstream ELF metadata defect rejected by modern
linkers. Exactly one byte changes at file offset 0x38E384. All loadable segment
bytes, symbols, relocations, dependencies and segment alignment are unchanged.

Modified SHA-256:

The transformation and before/after verification are reproducible with
scripts/normalize-runtime.ps1. No linker error checks are disabled.
Paddle headers are redistributed unmodified with their original notices.
FPInk's JNI preprocessing/postprocessing code is a new implementation, not the
questionnaire-gated shell demo. No gated source was accessed.
